# SIBUID

**Software Identity Binding Unique Identifier**

> An identity names an actor. A binding establishes what that actor currently is.

This repository is the source of truth for the SIBUID Reference Surface.

## Canonical positioning

A SIBUID is a unique identifier used to distinguish a defined software-identity binding within the continuity boundary established by a system's policy.

SIBUID is a **descriptive semantic term**, not a claim of a new Internet protocol, standards-track identifier, credential format, registry, or trust architecture.
